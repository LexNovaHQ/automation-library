# P0 Templates

## Purpose

This folder contains the highest-demand, highest-ROI template glue workflows.

P0 templates are the first commercial workflow assets for Upwork/Fiverr/client delivery.

## P0 Template Set

- `TPL-P0-001` Lead Intake to Qualification to Follow-up
- `TPL-P0-002` Form Submission to CRM Update to Team Alert
- `TPL-P0-003` CSV/Excel Cleanup to CRM Import
- `TPL-P0-004` Webhook to Normalize to API Sync
- `TPL-P0-005` AI Email Draft to Approval to Send
- `TPL-P0-006` Inbound Email to Extract to CRM Update

## Classification

Layer type: `TEMPLATE_GLUE`

## Build Rule

Template glue should not duplicate reusable component logic.

It should connect existing core components, component adapters, independent adapters, and client config assets into one sellable workflow.
