# CFG-003A - Client-Facing Tool Stack Form

## Purpose

This is the simplified client-facing version of the tool stack questionnaire.

It helps us understand which tools the client uses and what access/integrations are needed.

This form avoids internal terms like:

- adapter
- component
- handoff-only core
- Assembly Engine
- C2/C4/C5/C6 IDs
