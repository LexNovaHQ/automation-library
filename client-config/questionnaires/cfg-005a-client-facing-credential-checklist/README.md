# CFG-005A - Client-Facing Credential Checklist

## Status
Built v1.0

## Layer Type
CLIENT_CONFIG_ASSET

## Purpose
Simplified client-facing credential checklist.

This is the version that can be sent to a client through:

- Tally
- Google Forms
- Typeform
- Fillout
- Notion
- email
- discovery call

## File
- `../client-facing-credential-checklist.md`

## Difference From CFG-005
CFG-005 is the internal credential readiness checklist.

CFG-005A is the simplified client-facing version. It avoids internal terms such as adapter readiness, execution contract, classification matrix, and Assembly Engine.

## Output
Client answers from CFG-005A should be converted into the structured CFG-005 credential readiness response format.
