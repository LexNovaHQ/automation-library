# CFG-003A - Client-Facing Tool Stack Form

## Status
Built v1.0

## Layer Type
CLIENT_CONFIG_ASSET

## Purpose
Simplified client-facing tool stack form.

This is the version that can be sent to a client through:

- Tally
- Google Forms
- Typeform
- Fillout
- Notion
- email
- discovery call

## File
- `../client-facing-tool-stack-form.md`

## Difference From CFG-003
CFG-003 is the internal master questionnaire.

CFG-003A is the simplified client-facing version. It avoids internal terms such as adapters, components, handoff-only cores, C2/C4/C5/C6 IDs, and Assembly Engine.

## Output
Client answers from CFG-003A should be converted into the structured CFG-003 tool stack response format.
