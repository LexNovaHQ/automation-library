# CFG-002A - Client-Facing Workflow Discovery Form

## Status
Built v1.0

## Layer Type
CLIENT_CONFIG_ASSET

## Purpose
Simplified client-facing workflow discovery form.

This is the version that can be sent to a client through:

- Tally
- Google Forms
- Typeform
- Fillout
- Notion
- email
- discovery call

## File
- `../client-facing-workflow-discovery-form.md`

## Difference From CFG-002
CFG-002 is the internal master questionnaire.

CFG-002A is the simplified client-facing version. It avoids internal terms such as components, adapters, template glue, C2/C4/C5/C6 IDs, and Assembly Engine.

## Output
Client answers from CFG-002A should be converted into the structured CFG-002 job profile format.
