# Client Config

## Purpose

This folder contains reusable client configuration assets.

Client config assets turn hardcoded workflows into reusable templates.

## Subfolders

- `schemas/` — JSON schemas and structured config models
- `questionnaires/` — discovery questionnaires for client intake
- `generators/` — config generators that convert questionnaire answers into template config
- `examples/` — example client configs

## Classification

Layer type: `CLIENT_CONFIG_ASSET`
